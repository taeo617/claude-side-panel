# side-panel

A Claude Code mod that opens a pane beside the chat. It shows context token usage with progress bars,
cost and rate limits, mode buttons you can click to switch, and a persistent notes list.
Open it with `/side-panel` (it also opens on session start). The terminal should be at least 110 columns wide.

## Install

```
/plugin install side-panel --marketplace <owner>/<repo>
```
